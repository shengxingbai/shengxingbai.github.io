> 本文记录一次「把信息源自动化」的小实践：借助 WorkBuddy 安装开源项目 **ai-signal**，配置每日定时抓取 AI 一线动态，并通过 QQ 邮箱把整理好的日报推送到自己手里。

## 为什么想要一个 AI 日报

AI 领域的信息太碎了：X（Twitter）上的从业者、各路播客、Anthropic / OpenAI / DeepMind 的官方博客、arXiv 论文……分散在十几个地方，每天手动刷既费时又容易漏。

我想要的是：**每天一份、自动送达、只保留值得读的内容**。与其自己写爬虫，不如直接用现成的开源聚合器，再让 AI Agent 帮我做「总结 + 投递」。

## ai-signal 是什么

[ai-signal](https://github.com/Benboerba620/ai-signal) 是一个 **Agent-first** 的 AI 信息聚合项目，核心理念很巧妙：

- **中央只供料，不替你生成日报**。官方用 GitHub Actions 每天（北京时间约 06:00 全量抓取，工作日约 09:30 再做一次 arXiv 刷新）拉取播客、推文和论文，发布成一份 JSON。
- **真正的总结、翻译、格式定制，由你自己的 Agent 完成**。它追踪 15 个播客频道、29 位人物、19 个 X 账号、4 家博客和 arXiv 每日论文，覆盖面已经足够「一线」。
- **不需要内容侧的 API key**，clone 下来就能用。

## 用 WorkBuddy 一键安装

ai-signal 明确支持 WorkBuddy 的「自动安装」。我只在对话框里说了一句：

> 帮我安装 https://github.com/Benboerba620/ai-signal

WorkBuddy 自动完成了 clone、安装依赖（`pip install -r requirements.txt`，用户侧其实只需要 `httpx[socks]`）、并引导我初始化配置；随后立即生成了第一份日报。整个过程没敲命令、没找 API key。

手动方式也简单（供参考）：

```bash
git clone https://github.com/Benboerba620/ai-signal.git
cd ai-signal/scripts && pip install -r ../requirements.txt
```

> 国内 clone 慢的话，README 里给了镜像前缀：`https://gh-proxy.com/https://github.com/Benboerba620/ai-signal.git`。

## 让 Agent 每天定时抓取

中央的 feed 每天自动更新，我需要的是「我自己这边每天自动收」。在 WorkBuddy 里创建一条**每日定时任务（自动化）**即可，例如每天 08:00 触发一次「生成并发送 AI Signal 日报」。

要点：

- 定时任务建议给足超时（官方提示 ≥10 分钟，部分平台默认拉到 15 分钟，避免被杀死），可加 `--timeout-seconds 900` 一类参数；
- 抓取频率对齐中央节奏：上午 09:30 之后拿到的 arXiv 内容最全；
- 非持久化的 Agent 不适合自动收，用手动 `/ai-signal` 看日报即可。

## 把日报发送到 QQ 邮箱（通过连接器）

ai-signal 的推送渠道包含 **邮件**（另外还有 Telegram / 飞书 / 聊天）。但把日报真正发到我的 QQ 邮箱，这一步**不是手动去配 SMTP，而是通过 WorkBuddy 的邮件连接器完成的**。

做法很简单：

1. 在 WorkBuddy 里连接好「**QQ 邮箱 / 智能体邮箱**」连接器（它自带发信能力，鉴权由 WorkBuddy 托管）；
2. 在定时任务里让 Agent 生成日报后，直接通过连接器把内容投递到我的 QQ 邮箱。

也就是说，从「抓取 → 总结 → 发送」整条链路，都在同一个 Agent 对话里完成，零额外配置。

这样做的好处：

- 不用自己查 SMTP 服务器、端口，也不用单独申请 QQ 邮箱的**授权码**——这些琐碎的鉴权细节由连接器托管；
- 和安装、定时任务一样，发送也是「说一句话」就能接上的能力，可维护性更好。

> 📌 补充（非本次采用的方式）：如果不走连接器、想自己接邮件服务，QQ 邮箱的标准 SMTP 是 `smtp.qq.com:465`（SSL），密码要用**授权码**（邮箱设置 → 账户 → 开启 POP3/SMTP 获取），而不是 QQ 登录密码。本次实践并未采用这种手动方式。

## 效果与小结

打通之后，每天打开 QQ 邮箱就能看到一份由 Agent 生成、聚焦 AI 一线的中文日报——省去了自己四处刷信息的时间。

几个体会：

1. **Agent-first 的思路很省心**：抓取（中央）和总结（自己的 Agent）解耦，我只需要关心「怎么收、收到哪」。
2. **发邮件交给连接器最省事**：连接好 QQ 邮箱连接器后，发送由 WorkBuddy 托管鉴权，不用自己去折腾 SMTP 服务器、端口和授权码这类琐碎配置。
3. **定时任务的超时别设太短**：AI 总结 + 抓取一轮往往要几分钟，给够时间才稳。

如果你也想拥有一个不打扰、但每天都在线的 AI 资讯源，ai-signal + WorkBuddy + QQ 邮箱这套组合值得一试。


# 🧠 高手信息处理术：小白认知升级笔记（理论 + 行动版）

> 适用人群：总觉得信息太多、看完就忘、容易被带节奏、想提升判断力的初学者。  
> 核心目标：不追求“知道更多”，追求“判断更准”。建立你的“信息代谢系统”。

---

## 第一章：先搞懂大脑的“出厂设置”（为什么你总焦虑？）

在学方法之前，先接纳一个残酷事实：**你的大脑天生不适合处理海量信息**。这不是你笨，这是人类的生物性缺陷。下面的理论会告诉你“病根”在哪。

### 理论 1：认知负荷理论 —— “大脑的桌面只能摆 4 个杯子”
- **大白话**：你的工作记忆（短期记忆力）就像一张小小的电脑桌面，同时只能放得下 **3-4 个** 信息块。如果硬塞进 100 条新闻，桌面就崩了，你会陷入“选择瘫痪”。
- **理论支撑**：信息过载被明确定义为“决策者面对一组信息……其中不同规模和复杂程度的个体信息线索的累积，抑制了决策者最优确定最佳决策的能力”。信息量与决策准确性之间呈**倒 U 型曲线**关系。
- **高手思维**：信息不是越多越好。当信息量超过大脑承载力时，决策质量会断崖式下跌。
- ✅ **小白行动指南**：
  - **断舍离**：把你关注的公众号、新闻 APP 取关到只剩 **3-5 个** 核心信源。
  - **准则**：只看“原始材料”（如官方公告、财报原文）和“经过时间验证的深度分析”，取消关注所有“标题党”和“快讯轰炸机”。

---

### 理论 2：有限理性理论 —— “别妄想算出最优解”
- **大白话**：诺贝尔奖得主赫伯特·西蒙说，现实世界太复杂了，你永远不可能掌握全部信息。追求“最优选择”会累死你，且根本不存在。
- **理论支撑**：人类决策者是在**信息成本、算法复杂度和认知能力的三重约束下**做出决策。现实中遵循的是**“满意”原则（Satisficing）**——找到第一个满足最低标准的选项就停止搜索。
- **高手思维**：高手只找 **“足够好”** 的选项。看到第一个满足标准的解释就停下来，不再继续搜索。
- ✅ **小白行动指南**：
  - **设定“信息停止线”**：针对一个热点事件，只认真看 **2 篇** 深度报道（正反各一篇），然后就逼迫自己做出初步判断，**坚决不看第 3 篇、第 4 篇**。
  - **接受模糊**：允许自己对某些细节“不知道”，这很正常。

---

### 理论 3：确认偏误 + 动机性推理 —— “你的大脑会骗你”
- **大白话**：你刷手机时，会**下意识**只点开那些“让你舒服”（符合你既有观点）的文章。大脑还会主动扭曲新信息，把它改得符合你的老想法。这不是性格问题，这是生理本能。
- **理论支撑**：实验研究表明，持有更悲观先验信念的受访者显著倾向于选择悲观标题，提供了确认偏误的直接证据。而动机性推理在移民、气候变化、枪支管制等多个议题上均有体现，是解释信念偏差、政治极化和过度自信的核心机制。
- **高手思维**：凡是让自己“拍大腿叫绝”的信息，立刻警惕——这很可能是在强化你的偏见。
- ✅ **小白行动指南**：
  - **执行“反方搜索”**：看到一条让你热血沸腾的新闻，**立刻去搜一条立场完全相反的高质量评论**。比如看到“房价马上暴涨”，就去搜“房价必然腰斩的逻辑”。
  - **物理隔离**：不要用算法推荐的“兴趣首页”，改用**主动搜索**。

---

### 理论 4：把关人理论 —— “新闻是被‘加工’过的，不是原生态”
- **大白话**：你看到的每一条新闻，都经过了记者、编辑、老板、甚至算法的层层筛选和“剪辑”。就像综艺有剧本，新闻也有取舍。
- **理论支撑**：把关人理论（Gatekeeper Theory）由库尔特·卢因于 1947 年提出。在数字时代，算法已成为新型“数字把关人”，信息中介的过滤、分类和个性化算法能够影响新闻话题的准确性，并产生“媒介效果”。
- **高手思维**：信息即权力。谁在传播，谁就在定义事实。
- ✅ **小白行动指南**：
  - **“三问”识破滤镜**：
    1. 这个信息是谁发的？（官方？自媒体？利益相关方？）
    2. 他为什么要现在发？（抢流量？稳定情绪？掩护出货？）
    3. **他没说什么？**（这是最关键的，被隐藏的部分往往是真相的核心。）

---

### 理论 5：专家 - 新手差异 —— “高手脑里有地图，新手眼里是碎片”
- **大白话**：新手看新闻是“一块块砖头”，高手看新闻是“一栋栋楼”。因为高手脑子里预装了**思维模型**（比如供需关系、二八定律），新信息进来自动归位。
- **理论支撑**：认知科学研究证明，专家拥有**长期工作记忆**的编码优势，能更好地区分相关与不相关信息，并将新信息更快地整合到已有分析框架中。专家受自身知识体系的引导，将注意力集中在搜索相关信息上；而缺乏足够知识的新手在信息搜集过程中则不那么聚焦于有用信息。
- **高手思维**：花 80% 时间搭建思维脚手架，花 20% 时间填充信息。
- ✅ **小白行动指南**：
  - **刻意练习“归类”**：读完新闻后，强制自己回答：**“这属于供需变化、政策干预、还是情绪恐慌？”**
  - **先学模型，再读新闻**：花一周时间只研究“供需理论”和“二阶效应”（即“这事发生后，接下来会发生什么？”），再去套用看新闻。

---

## 第二章：高手每日“信息代谢”SOP（小白照抄版）

别管理论了，如果你懒得看上面，直接按这个**每日 4 步流程**操作：

| 步骤 | 动作 | 时间 | 核心心法 |
| :--- | :--- | :--- | :--- |
| **① 信源筛选** | 只看固定 3 个深度源头，拒绝推送 | 5 分钟 | 质量 > 数量（认知负荷理论） |
| **② 48 小时冷静期** | 重大突发新闻，**前 24 小时只看数据**（伤亡/涨幅/条款），不看评论 | 0 分钟（等待） | 避开第一波情绪裹挟（有限理性） |
| **③ 强制输出** | 用 **50 个字**写下来：“这对我的工作/生活意味着什么？” | 10 分钟 | 写不出来的理解都是幻觉（专家框架） |
| **④ 反方校验** | 搜一条反对意见看看 | 5 分钟 | 破除确认偏误 |

---

## 第三章：给新手的“认知急救包”（遇到新闻就套用）

当你看到任何一条重大新闻时，**默念下面 4 个问题**，你的理解力瞬间超越 90% 的人：

1. **【利益链】** 这消息出来后，**谁最高兴？谁最受伤？**
2. **【真伪性】** 这是 **“短期波动”** （比如库存变化）还是 **“长期结构变化”** （比如 AI 取代人工）？
3. **【二阶效应】** 如果大家都按这个新闻去操作（比如都去抢盐），那么**接下来的机会**在哪里（比如卖盐的股票反而不能追）？
4. **【定价了吗】** 这个利好/利空，**是不是已经涨完/跌完了？** （如果人尽皆知，往往意味着价格已反映）。

---

## 第四章：一周速成计划（打卡清单）

- **Day 1-2**：清理手机订阅，只保留 **3 个** 付费或深度类 APP。
- **Day 3-4**：选一个热点，只读 **2 篇** 文章，写 50 字短评，**绝不看评论区**。
- **Day 5-6**：试着找到一篇反驳你自己观点的文章，耐心看完。
- **Day 7**：复盘，你会发现这周焦虑感明显下降，看事情清晰了很多。

## 🏆 终极心法（贴在桌上）

> **高手与普通人的区别：**  
> 普通人刷新闻，是为了**缓解焦虑**（我看过了，我知道了）。  
> 高手读新闻，是为了**修正模型**（这件事改变了我对世界的哪个认知？）。

**记住：你不是读得太少，你是想得不够深。慢下来，比较快。** 🚀
