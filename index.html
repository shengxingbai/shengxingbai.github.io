关于本站

这是一个基于 GitHub Pages 发布的静态个人网站，包含个人简历、 个人博客与个人荣誉三个核心模块。网站采用 Jekyll 构建， 提交到 GitHub 后会自动发布到 *.github.io 域名，无需任何服务器运维。

你可以在简历页查看教育背景、工作经历与技能；在博客页阅读按分类组织的文章； 在荣誉页了解奖项、证书与主要成就。
